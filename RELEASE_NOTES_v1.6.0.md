# islamic_utility v1.6.0

This release corresponds to the repository tag `v1.6.0`. It contains the
cache-first official Hijri lookup and refresh changes, range consistency and
cache improvements, HTTP ETag and timeout handling, next-event prayer API and
options, next-day boundary handling, and the high-latitude Fajr/Isha fallback
duration correction.

The subsequent prayer-engine accuracy work, LFNU preset, observer elevation,
astronomical solver changes, event provenance API, comparison datasets, and
expanded regression/documentation suite are recorded in
[`RELEASE_NOTES_v2.0.0.md`](RELEASE_NOTES_v2.0.0.md).
